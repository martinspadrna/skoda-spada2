# O aplikaci – souhrn v.1.5 901–950 po v925

Build v925 navazuje na formální auditní uzávěrku v924. Nepřidává nové zásahy do Supabase, online flow ani gameplaye, ale připravuje praktickou validační fázi: ruční mobilní smoke checklist, Playwright runbook, post-release/PWA validační postup a read-only helpery pro jasné odlišení „připraveno“ vs. „musí otestovat člověk“. Historie v O aplikaci zůstává stručná po blocích, ne po každém mikrobuildu.
