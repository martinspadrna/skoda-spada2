# RaK v.1.5 (940) – Obsazenost strojů: jemný theme tint v poli grafu

- Pod čarou grafu už není plná area fill vrstva.
- Místo ní je přes celé pole grafu jemný theme tint, aby graf nepůsobil černě ani úplně prázdně.
- Tint se kreslí jako samostatný SVG rounded rect s explicitní rgba barvou dopočtenou z aktuálního theme.
