# RaK v.1.5 (930) – stručný souhrn pro O aplikaci

Blok `v.1.5 901–950` zůstává stručný a neobsahuje mikrovýpis každého buildu.

Doplněná informace pro v930:

- Rotace: stabilní spodní dock jmen bez opožděného přepočítávání pozice po otevření stránky.
- Rotace: dlaždice se jmény vrácené na větší, čitelnější velikost.
- Dashboard: průhlednější iOS glass vzhled podle aktivního tématu.
- Dashboard: ikonky v kartách jsou bez vlastní barevné kapsle/pozadí.
- Láďův/low-end režim dál drží odlehčenou variantu bez těžkého blur efektu.
