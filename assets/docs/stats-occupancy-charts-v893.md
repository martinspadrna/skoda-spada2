# RaK v.1.5 (893) – Statistiky: obsazenost a absence

- Box obsazenosti strojů je zkrácený bez dlouhého textového vysvětlení.
- Levá polovina ukazuje čárový graf vývoje obsazenosti během započtených měsíců roku.
- Pravá polovina ukazuje barevný koláč důvodů absencí za započtený rok.
- Každý důvod absence má vlastní výkroj/barvu a odpovídající legendu.
- Kód `N` se nově zobrazuje jako `Neschopenka`.
- Budoucí nahrané měsíce se dál nezapočítávají, dokud daný měsíc nezačne.
