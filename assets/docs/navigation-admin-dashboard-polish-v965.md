# Navigace, Dashboard a administrace v965

Spodní navigace se zúžila na pět tlačítek: Home, Rotace, Kalkulačky, Hry a Více. Rozpisy a Statistiky zůstávají dostupné jedním klepnutím z Rotace přes rychlá glass tlačítka.

V administraci se z Přehledu připojení odstranilo testovací tlačítko „Zapsat mě teď“ a údaj o stránce. Displej nově ukazuje viewport/screen rozlišení a DPR, aby šlo ladit appku podle skutečných zařízení.

Dashboard má jemnější dorovnání horního panelu pro viewporty 412×918 a 430×932.
