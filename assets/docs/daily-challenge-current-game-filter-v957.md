# RaK v.1.5 (957) – Daily challenge: výsledky jen pro aktuální denní hru

- Daily challenge má nově vlastní leaderboard podle aktuálně vybrané denní hry.
- Například když je dnes Pexeso, top výsledky v Daily challenge se berou z `daily_memory`, ne ze společného mixu všech Daily challenge her.
- Souhrnný `daily` záznam zůstává pro achievementy a celkové počty splněných challenge.
