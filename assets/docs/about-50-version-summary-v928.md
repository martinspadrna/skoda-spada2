# RaK v.1.5 901–950 – stručný souhrn po v928

Blok 901–950 řeší hlavně uzavření auditů, stabilitu release procesu, herní profily, achievementy, odměny za vzhled a menší mobilní UI opravy.

## Hlavní změny

- Dokončené auditní a prompt-compliance dokumenty pro architekturu, bezpečnost, výkon, stabilitu, rollout a rollback.
- Přidané validační runbooky pro ruční mobilní testy, Playwright smoke a post-release/PWA kontrolu.
- Hry dostaly rozšířené achievementy, D-směnové cíle a odměnová témata/pozadí.
- Aktivní téma a pozadí se ukládají na přihlášený profil.
- Top score ve hrách zobrazuje čas čitelněji včetně datum/čas pravidel podle předchozích buildů.
- Rotace dostala stabilnější spodní seznam jmen nad navigací.
- Láďův režim byl znovu odlehčen pro slabší mobily.

## Stav

- Dokumentační část auditních promptů je uzavřená.
- Zbývají reálné mobilní testy, Playwright run a konkrétní chyby nalezené při používání.
