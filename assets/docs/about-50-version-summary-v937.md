# RaK v.1.5 (937) – stručný souhrn pro O aplikaci

V937 dočišťuje měsíční graf obsazenosti strojů: plocha pod/mezi body už nemá fallbackovat do černé a používá stabilní průhlednou theme výplň. Zároveň přidává bezpečný Playwright monkey test, který náhodně prochází aplikaci bez destruktivních online/admin akcí a hlídá pády, bílé obrazovky a zásadní JS chyby.
