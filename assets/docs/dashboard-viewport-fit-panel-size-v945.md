# RaK v.1.5 (945) – Dashboard: lehce větší panely ve viewport-fit režimu

- V944 byl horní směnový panel opravený, ale běžné dashboard panely byly na 360×800 pořád zbytečně malé.
- V945 běžné panely na malém displeji mírně rostou, aby využily volné místo nad spodní lištou.
- Horní panel se směnou se dál chrání proti přílišnému zmenšení.
- Cíl je lepší čitelnost bez návratu ke zbytečnému scrollu.
