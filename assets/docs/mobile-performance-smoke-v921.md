# RaK v.1.5 (922) – Mobile/performance smoke plán

## Cíl

Doplnit poslední praktickou část velkého auditu: co přesně změřit na mobilu a jak to vyhodnotit bez zásahu do hotových funkcí.

## Ruční měření

- cold load po vyčištění cache / nové verzi,
- warm load po běžném návratu do PWA,
- přepnutí Dashboard → Hry → Reaction Test → Denní challenge,
- start hry a zobrazení Top score nad spodní lištou,
- O aplikaci / Diagnostika: release gates a due diligence progress.

## Zařízení

- Samsung A15/A14 class: primární mobilní smoke,
- iPhone 13 Pro Max class: široký viewport,
- desktop Edge F12: rychlá regresní kontrola.

## Stav

Read-only plán je hotový. Skutečné měření je stále ruční krok a nemá se vydávat za provedené, dokud opravdu neproběhne.
