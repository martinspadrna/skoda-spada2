# RaK v.1.5 (943) – Dashboard viewport-fit

- Dashboard má novou výškově řízenou responzivní vrstvu pro 360×800 a podobné displeje.
- Kompaktní režim se spíná podle šířky i výšky viewportu, ne jen podle šířky.
- Zmenšuje padding, mezery, hero kartu, dashboard dlaždice, popisky a ikony.
- Cíl: na běžném testu 360×800 se Dashboard vejde bez zbytečného scrollu, zatímco větší mobily zůstanou vizuálně pohodlnější.
- Reálné ověření na fyzických mobilech musí proběhnout ručně.
