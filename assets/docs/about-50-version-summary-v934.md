# RaK v.1.5 (934) – stručný souhrn pro O aplikaci

Build v934 dál ladí Dashboard po v933. Karty jsou tmavší, jednotnější a průhlednější, bez lokálních světlých fleků na každé buňce. Aktivní ikonky spodního panelu i ikonky na Dashboardu víc přebírají barvu aktivního tématu. Oznámení na Dashboardu má volitelný nadpis, přepínače „Aktivní“ a „Text má jezdit“ jsou kvůli úspoře místa vedle sebe a ticker už neopakuje zadaný text dvakrát; zobrazí se jen text a potom mezera. Supabase DB, policies, online flow a gameplay zůstávají beze změny.
