# RaK v.1.5 (942) – kritický fallback proti bílé stránce s velkými ikonami

- Do hlavičky přidán malý kritický CSS fallback.
- Fallback drží tmavé pozadí aplikace, skrývá neaktivní stránky a omezuje velikost ikon spodní navigace i při pozdním/selhaném načtení hlavních CSS.
- Plný vzhled dál dodávají standardní CSS soubory.
