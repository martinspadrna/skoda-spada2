# RaK v.1.5 (931) – stručný souhrn pro O aplikaci

Doplněná informace pro blok v.1.5 901–950:

- V931 sjednocuje ovládání korekcí: Frézky mají u aktuální korekce konicity a fhβ stejné přepínání znaménka `+ / −` jako korekce na soustruhách.
- Změna je cílená jen na UI zadávání hodnot; samotný výpočet konicity a fhβ zůstává zachovaný.
